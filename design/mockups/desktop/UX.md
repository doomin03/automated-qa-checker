# Desktop UX 제안

목표는 사용자가 **무엇을 작성하고 있는지, 실행해도 되는지, 어디에서 실패했는지**를 같은 작업 문맥 안에서 이해하는 것이다. 기능을 추가하는 대신 기존 Desktop 기능의 배치와 표현을 검토한다.

## 작업 흐름

**목록 → Flow/XML 작성 → 검증 → 명시 실행 → 단계별 결과 → 공유**

목록은 이름·상태·위치·최근 수정으로 구성한다. 편집에서는 왼쪽 탐색, 중앙 단계/원문, 오른쪽 선택 단계 속성을 사용한다. 상단의 검증·실행이 주요 행동이고, 공유는 보조 행동이다. 검증 결과는 편집 내용 아래에 붙여 원인과 다음 행동을 연결한다.

현재 초안과 실행 대상을 화면에 표시하고 검증 후 한 번의 실행 클릭으로 시작한다. 반복 확인 dialog는 사용하지 않는다. XML 변경은 검증을 무효화하고 실행 버튼을 잠근다. 가져오기·공유·검증으로 자동 실행하지 않는다. CLI 경로, token 같은 연결 정보는 주 작업에 섞지 않으며 이번 목업은 기술정보를 접힌 영역에만 둔다.

## 결과의 정보 위계

첫 줄에서 판정과 요약 원인을 읽고, 아래에서 해당 단계와 기대값/실제값을 비교한다. 상세 로그는 필요할 때 펼친다. 화면을 검정·회색으로 출력해도 결과를 읽을 수 있게 상태명·테두리·설명을 함께 쓴다.

| 상태 | 사용자에게 전달하는 의미 | 다음 행동 |
| --- | --- | --- |
| 검증 전 / 재검증 필요 | 실행할 초안이 아직 확인되지 않음 | 검증 |
| 실행 중 | 진행된 단계와 대기 단계가 다름 | 진행 확인 또는 중단 |
| PASS | 모든 확인을 통과 | 결과 확인·공유 |
| FAIL | 실행한 검증이 기대값과 불일치 | 실패 단계·값 확인, 편집 |
| 환경 오류 | 실행 환경 준비 문제, QA 실패와 별개 | 대상 연결 확인 |
| 미실행 | 해당 단계를 실행하지 않아 판정 없음 | 원인 확인 후 명시 실행 |
| 중단 | 사용자 중단, 진행한 단계와 미실행을 보존 | 편집 또는 새 실행 |

공유 초안 제출, 업무 상태 변경, 검토 완료는 QA outcome을 바꾸지 않는다. 공유 초안 요청과 검수·발행도 분리한다.

## 시각 규칙

밝은 회색 배경, 흰 패널, 얇은 경계선과 여백으로 영역을 구분한다. 파란색 하나를 주요 행동·선택에만 쓴다. 그라데이션과 장식 그림은 없으며 버튼은 아이콘 없이 동사로 쓴다. 로고 문자와 간단한 연결선 외 장식은 최소화한다. 1440px에서는 Flow와 속성을 함께 보고 1024px에서는 속성을 아래로 배치한다.

## 현재 기능과 목업의 차이

| 항목 | 현재 제품 기능 | 이번 검토 파일 |
| --- | --- | --- |
| Flow/XML | Flutter 편집·공개 CLI 검증 | 고정 Flow 선택, XML 텍스트 입력·문법 검사 |
| 명시 실행 | 독립 Engine CLI, 실제 event/result | 타이머와 예시 값의 상태 전환 |
| 실행 결과 | 실제 단계·증거·판정 | 정보 위계·실패 설명·미실행 표현 제안 |
| 공유 | 인증된 Registry 수신·pin·초안·검수 | 네트워크 없는 초안 제출 화면 제안 |
| 환경/연결 | 별도 설정과 장치/연결 상태 확인 | 접힌 설명 영역, 실제 연결 없음 |
| 이 화면 배치 | 기존 Flutter의 기능 중심 화면 | 새 배치 검토안, 제품 미이식 |

블록 추가·드래그·속성 저장·XML→Flow 변환·실제 증거 이미지·실행 이력 보관은 목업 범위 밖이다. XML은 공개 예시 원문이며 수정된 XML로 실제 동작을 수행하지 않는다. 목록 두 행의 과거 상태도 예시 데이터다. 새로고침하면 편집과 결과가 초기화된다.

## 확인한 상호작용

목록 검색과 빈 상태, 단계 선택, XML 전환·오류·복원, 변경 후 검증 무효화, 검증만으로 실행되지 않음, 한 번의 명시 실행, PASS/FAIL/환경 오류/미실행, 진행 중단, 공유 dialog Escape와 focus 복귀, 공유 후 QA 판정 보존, 두 Desktop 너비를 Chromium에서 검증했다. [verification.json](verification.json)에 검사 목록과 브라우저 버전이 있다. 키보드 focus를 제공하지만 전체 접근성 인증을 수행한 것은 아니다.
