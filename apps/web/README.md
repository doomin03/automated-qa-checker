# 사용자 QA 웹

React app/pages/widgets/entities 구조로 JSON 가져오기·편집·내보내기, Blueprint node/edge, event replay와 파일 따라가기를 제공한다. 루트의 pnpm run dev:web로 실행한다. 사용자 Flutter Desktop이나 서버 로그인 기능을 대체하지 않는다.

목표는 공용·사용자 테스트 시나리오 XML 전달과 진행 확인이다. 관리자 권한업무도 후속으로 제공하며 웹 전체를 관리자 전용으로 한정하지 않는다. XML 내보내기 중간 수정은 아직 미검증이며 OpenSpec 정합 후 인수한다.
